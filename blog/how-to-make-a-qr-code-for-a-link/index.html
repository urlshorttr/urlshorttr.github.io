How to Make a QR Code for a Link, and Save It as PNG or SVG

October 11, 2026 · 2 min read

A QR code is a square pattern that a phone camera reads as text, usually a web address. Making one takes under a minute.

Steps

  1. Open the QR code generator.
  2. Paste your link into the box. The code appears as you type.
  3. Pick a download size. Medium is fine for most screens. Choose large for print.
  4. Leave the error correction on Medium unless the code will be worn or partly covered.
  5. Press Download PNG or Download SVG.
  6. Scan the saved file with a phone before you use it.

PNG or SVG?

A PNG is a pixel image. It is the simplest choice for documents, slides and websites. An SVG is a vector file that stays sharp at any size, so it is the better choice for posters, packaging and anything a printer will handle.

Make the code simpler with a short link

The more text a QR code holds, the more squares it needs, and the smaller each square becomes. If your address is long, shorten it first and make the code from the short link. The result is easier to scan from a distance.

Check before you share

  • Scan it with at least one phone, in the place where it will be used.
  • Make sure the link opens the page you expect.
  • Keep the white border around the code.
