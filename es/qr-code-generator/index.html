Generador de códigos QR

Escribe una dirección web o cualquier texto y el código aparece al instante. Descárgalo en PNG para documentos y pantallas, o en SVG para imprimir. Nada de lo que escribes sale de tu dispositivo.

Tu código QR aparecerá aquí.

¿Qué archivo debo descargar?

PNG
Una imagen hecha de píxeles. Úsala en documentos, presentaciones, sitios web y mensajes. Elige el tamaño grande si se va a imprimir.
SVG
Un archivo vectorial que se ve nítido a cualquier tamaño. Envíalo a la imprenta o úsalo en carteles y envases.

Consejos para un código que se escanee bien

  • Un código oscuro sobre fondo claro se escanea mejor. Mantén un contraste alto.
  • Deja el borde blanco. Los lectores lo necesitan para encontrar los límites.
  • Un texto más corto da un código más simple. Para una dirección larga, acorta primero el enlace.
  • Más corrección de errores ayuda a que el código resista el desgaste, pero hace los cuadros más pequeños.
  • Prueba con un teléfono antes de imprimir. Nuestra guía de tamaño y contraste tiene los detalles.

Preguntas frecuentes

¿Este generador de códigos QR es gratis?

Sí. Sin registro, sin marca de agua y sin límite de descargas.

¿Caduca el código QR?

No. El código es el propio texto dibujado en cuadros, así que funciona mientras exista la página o el texto que contiene. Es un código estático, no con seguimiento.

¿Se envía mi texto a un servidor?

No. El código se dibuja en tu navegador. Si además quieres un enlace corto, usa el acortador de URL, que envía la dirección a nuestro servicio de enlaces.

¿Qué puedo poner en un código QR?

Lo más habitual es una dirección web, pero sirve cualquier texto, hasta unos 2900 caracteres con la corrección de errores más baja. Si ves un aviso de que el texto es demasiado largo, acórtalo.

¿Puedo imprimir el código en un producto o un cartel?

Sí. Descarga el SVG, conserva el borde y comprueba el escaneo en una prueba impresa.
