Link kürzen. QR-Code dazu erhalten.

Fügen Sie eine lange Webadresse ein und erhalten Sie eine kurze, die Sie kopieren, teilen oder drucken können. Der QR-Code wird auf Ihrem Gerät gezeichnet und als PNG oder SVG heruntergeladen. Ein Konto ist nicht nötig.

Eigenes Ende wählen (optional)

5 bis 30 Buchstaben, Ziffern oder Unterstriche. Ist es schon vergeben, wählen Sie ein anderes.

Link öffnen

Letzte Links auf diesem Gerät

    Sie werden nur in diesem Browser gespeichert.

    So funktioniert es

    1. Link einfügenJede http- oder https-Adresse funktioniert, auch lange mit Tracking-Parametern.
    2. KürzenUnser Link-Dienst speichert Ihre Adresse und gibt eine kurze auf urlshort.tr zurück. Fügen Sie ein eigenes Ende hinzu, wenn sie gut lesbar sein soll.
    3. Kopieren oder scannenKopieren Sie den Kurzlink oder laden Sie seinen QR-Code für Flyer, Speisekarte, Folie oder Produktetikett herunter.

    Wann ein Kurzlink hilft

    Nachrichten und Profile
    Ein Kurzlink braucht weniger Platz in einer Bio, einer Nachricht oder einer Bildunterschrift und bricht nicht über drei Zeilen um.
    Alles Gedruckte
    Der QR-Code eines Kurzlinks hat weniger und größere Quadrate als der einer langen Adresse und lässt sich deshalb aus der Ferne oder auf kleinen Etiketten leichter scannen. Lesen Sie unseren Druckratgeber, bevor Sie ein Layout an die Druckerei schicken.
    Folien, Videos und Podcasts
    Man kann einen Kurzlink von einem Bildschirm abtippen, und Sie können ihn laut sagen, ohne einen Absatz voller Zeichen vorzulesen.
    Unübersichtliche Adressen aufräumen
    Aus Shops, Karten und Suchergebnissen kopierte Links tragen oft lange Zeichenfolgen hinter dem Fragezeichen. Ein Kurzlink verbirgt dieses Durcheinander beim Teilen.

    Was Sie vor der Nutzung wissen sollten

    • Kurzlinks werden auf urlshort.tr erstellt und leiten zu der Adresse weiter, die Sie eingegeben haben. Eine Anmeldung ist nicht nötig.
    • Ein Link lässt sich nach dem Erstellen nicht mehr ändern. Prüfen Sie die Adresse, bevor Sie auf die Schaltfläche drücken.
    • Jeder, der einen Kurzlink hat, kann ihn öffnen. Kürzen Sie keine Seiten, die privat bleiben sollen.
    • Links zu anderen Kürzungsdiensten werden nicht akzeptiert, und schädliche Links werden entfernt.
    • Sie können sehen, wohin ein Kurzlink führt, bevor Sie ihn öffnen: Hängen Sie ein Pluszeichen (+) an das Ende des Links oder nutzen Sie den Link-Prüfer. Unser Ratgeber zum Prüfen von Kurzlinks erklärt mehr.
    • Schädlichen Link gefunden? Melden Sie ihn.

    Häufig gestellte Fragen

    Ist dieser URL-Kürzer kostenlos?

    Ja. Es fällt nichts an und eine Anmeldung gibt es nicht. Die Website finanziert sich durch Werbung.

    Laufen Kurzlinks ab?

    Es wird kein Ablaufdatum festgelegt. Ein Link funktioniert, bis er entfernt wird, zum Beispiel nach einer Missbrauchsmeldung. Bewahren Sie die ursprüngliche Adresse bei wichtigen Dingen sicher auf.

    Kann ich das Ziel eines Kurzlinks ändern?

    Nein. Ein Kurzlink zeigt auf die Adresse, mit der er erstellt wurde. Zieht die Zielseite um, erstellen Sie einen neuen Kurzlink und ersetzen Sie den alten.

    Verfolgen Sie Klicks?

    Nein. Der Dienst zählt keine Klicks und erstellt keine Profile der Personen, die einen Link öffnen.

    Speichern Sie die Links, die ich kürze?

    Ja, die Adresse und ihr kurzes Ende werden in unserem Link-Dienst gespeichert, denn so funktioniert die Weiterleitung. Es gibt keine Konten. Ein kurzer Verlauf Ihrer letzten Links liegt außerdem in Ihrem eigenen Browser und lässt sich jederzeit löschen.

    Funktioniert der QR-Code auf jedem Handy?

    Es ist ein Standard-QR-Code, den aktuelle Handykameras und Scanner-Apps lesen. Testen Sie einen Code immer mit einem Handy, bevor Sie drucken, und lassen Sie den weißen Rand stehen.

    Kann ich den QR-Code auf Drucksachen oder Produkten verwenden?

    Ja. Laden Sie das SVG herunter, wenn die Druckerei eine Vektordatei verlangt, oder das PNG für Dokumente und Bildschirme. Stellen Sie sicher, dass Sie auf die Seite verlinken dürfen, auf die der Code zeigt.
