Prüfen, wohin ein Kurzlink führt

Fügen Sie einen Kurzlink dieser Website ein. Sie sehen zuerst die vollständige Adresse und entscheiden, ob Sie weitergehen.

Weitere Möglichkeiten zum Prüfen

  • Hängen Sie ein Pluszeichen (+) an das Ende eines beliebigen Kurzlinks dieser Website und öffnen Sie ihn. Sie erhalten dieselbe Vorschauseite.
  • Dieses Werkzeug funktioniert nur für Links, die auf dieser Website erstellt wurden. Bei anderen Diensten suchen Sie deren eigene Vorschaufunktion.
  • Lesen Sie unseren Ratgeber, wie Sie erkennen, ob ein Kurzlink sicher ist.
  • Schädlichen Link gefunden? Melden Sie ihn.
