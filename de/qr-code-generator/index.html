QR-Code-Generator

Geben Sie eine Webadresse oder einen beliebigen Text ein, und der Code erscheint sofort. Laden Sie ihn als PNG für Dokumente und Bildschirme oder als SVG für den Druck herunter. Nichts, was Sie eingeben, verlässt Ihr Gerät.

Ihr QR-Code erscheint hier.

Welche Datei soll ich herunterladen?

PNG
Ein Bild aus Pixeln. Verwenden Sie es in Dokumenten, Folien, Websites und Nachrichten. Wählen Sie die große Größe, wenn gedruckt wird.
SVG
Eine Vektordatei, die in jeder Größe scharf bleibt. Schicken Sie diese an die Druckerei oder nutzen Sie sie für Schilder und Verpackungen.

Tipps für einen scanbaren Code

  • Dunkler Code auf hellem Hintergrund lässt sich am besten scannen. Halten Sie den Kontrast hoch.
  • Lassen Sie den weißen Rand stehen. Scanner brauchen ihn, um die Ränder zu finden.
  • Kürzerer Text ergibt einen einfacheren Code. Bei einer langen Adresse kürzen Sie zuerst den Link.
  • Höhere Fehlerkorrektur hilft dem Code, Abnutzung zu überstehen, macht die Quadrate aber kleiner.
  • Testen Sie vor dem Druck mit einem Handy. Unser Ratgeber zu Größe und Kontrast enthält die Einzelheiten.

Häufig gestellte Fragen

Ist dieser QR-Code-Generator kostenlos?

Ja. Ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung der Downloads.

Läuft der QR-Code ab?

Nein. Der Code ist der Text selbst, als Quadrate gezeichnet, und funktioniert, solange die enthaltene Seite oder der Text existiert. Es ist ein statischer Code, kein verfolgter.

Wird mein Text an einen Server gesendet?

Nein. Der Code wird in Ihrem Browser gezeichnet. Wenn Sie zusätzlich einen Kurzlink möchten, nutzen Sie den URL-Kürzer, der die Adresse an unseren Link-Dienst sendet.

Was kann ich in einen QR-Code packen?

Am häufigsten ist eine Webadresse, aber jeder Text funktioniert, bis zu etwa 2.900 Zeichen bei der niedrigsten Fehlerkorrektur. Erscheint die Meldung, der Text sei zu lang, kürzen Sie ihn.

Kann ich den Code auf ein Produkt oder Plakat drucken?

Ja. Laden Sie das SVG herunter, behalten Sie den Rand und prüfen Sie den Scan zuerst an einem Probedruck.
