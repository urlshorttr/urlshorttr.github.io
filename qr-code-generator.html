Which file should I download?

PNG
A picture made of pixels. Use it in documents, slides, websites and messages. Pick the large size if it will be printed.
SVG
A vector file that stays sharp at any size. Send this to a printer, or use it for signs and packaging.

Tips for a code that scans

  • Dark code on a light background scans best. Keep the contrast high.
  • Leave the white border in place. Scanners need it to find the edges.
  • Shorter text makes a simpler code. For a long address, shorten the link first.
  • Higher error correction lets a code survive wear, but it makes the squares smaller.
  • Test with a phone before you print. Our size and contrast guide has the details.

Frequently asked questions

Is this QR code generator free?

Yes. There is no sign-up, no watermark and no limit on downloads.

Does the QR code expire?

No. The code is the text itself drawn as squares, so it works for as long as the page or text it holds exists. This is a static code, not a tracked one.

Is my text sent to a server?

No. The code is drawn in your browser. If you want a short link as well, use the URL shortener, which does send the address to is.gd.

What can I put in a QR code?

A web address is the most common choice, but any text works, up to a limit of roughly 2,900 characters at the lowest error correction. If you see a message that the text is too long, shorten it.

Can I print the code on a product or a poster?

Yes. Download the SVG, keep the border, and check the scan on a printed proof first.
