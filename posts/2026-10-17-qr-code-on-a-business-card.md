A business card has very little room, and a QR code lets you point to much more than fits on it: a website, a portfolio, a booking page or an online profile. Used well, it saves the other person typing and turns a card into a doorway. Used badly, it is a grey square that wastes space. Here is how to get it right.

## Decide what the code should open

Choose one clear destination. The best options are:

- **Your website or portfolio**, if it is the main thing people should see.
- **A booking or contact page**, if you want people to get in touch.
- **A professional profile**, if you work mainly through a network.
- **A short landing page** with your key links, if you need to offer several things.

Avoid sending people to a page that is hard to read on a phone, or that asks them to log in. People scanning a card are curious, not committed, so the page they land on needs to work at once.

## Make the link short and readable

A business card is printed in small numbers and kept for years, so the link inside the code should be stable. Make a short link with a readable ending, such as `urlshort.tr/jane_design`, using the [URL shortener](/). A short link gives a simpler code with larger squares, which prints better at small sizes. It also gives you a readable address to print under the code for people who would rather type it.

Because a short link cannot be edited, point it at a page address that you will keep for a long time, such as your main domain, and update the content of that page when things change.

## Choose the code type

Create a standard static code in the [QR code generator](/qr-code-generator/). It never expires and needs no subscription. If you would like the card to save your contact details directly, you can encode a contact card text format, but that makes the code much denser, and a dense code is hard to scan at card size. A short link to a contact page is usually the better choice.

## Size and placement

- **Minimum size:** about 2 cm by 2 cm. Smaller than that and many phones struggle, particularly in dim light.
- **Quiet zone:** keep a clear white margin of at least four modules around the code. Do not let text, lines or a coloured border touch it.
- **Placement:** the back of the card is the usual place. It leaves the front free for your name and details.
- **Orientation:** keep the code upright and square. Never stretch it to fit.

## Colours and finish

Black on white is the safest choice. If your brand uses colour, make the squares a dark shade and keep the background light. Test the colours with the generator, which warns you when contrast is low. Matte paper is easier to scan than a glossy finish that reflects light. If you use a dark card, print the code on a white panel instead of reversing it out.

## Add a short instruction

Many people do not know what to do with a code. A few words such as "Scan to see my work" next to the square tells them it is for them, and that it is safe to scan. Add the short link underneath in small text as a backup.

## Test before you order 500 cards

1. Print a copy at the real size on the same type of paper if you can.
2. Scan it with two or three different phones, including an older one.
3. Scan it indoors and in daylight.
4. Open the page on mobile data and check that it loads quickly.
5. Ask a friend to try it without any instructions.

If any scan is slow, make the code larger, shorten the link or raise the contrast. Our guide to [why a QR code is not scanning](/blog/why-your-qr-code-is-not-scanning/) lists the usual causes.

## Digital cards work the same way

If you share a card as an image or a PDF, the same advice applies. Keep the code large on the screen, because people may scan from a laptop with their phone. Download the PNG at a large size for screens, and the SVG if a printer asks for a vector file.
