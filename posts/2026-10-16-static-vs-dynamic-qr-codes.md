You will often see "dynamic QR codes" advertised, usually with a monthly price. Before you pay for one, it helps to understand the difference and to know when a free static code is the better choice.

## Static QR codes

A static code contains the destination itself. If you make a code for `https://example.com/menu`, those exact characters are drawn into the squares. A phone reads them and opens that page. No other service is involved.

**Good points**

- It works for as long as the destination page works.
- There is no subscription, and nothing can expire or be switched off.
- Nobody sits in the middle, so there is no tracking and no extra step.
- It is quick to make and free.

**Limits**

- You cannot change the destination after printing. If the page moves, the code points to the old address.
- There are no scan statistics.
- The more text it holds, the denser and harder to scan it becomes.

## Dynamic QR codes

A dynamic code contains a short address that belongs to the QR service. When a phone scans it, the service looks up the real destination and redirects the phone. Because the redirect is stored on the service, the owner can change the destination later, and the service can count scans.

**Good points**

- You can fix a wrong link or redirect to a new page without reprinting.
- The code is short, so the squares are larger.
- You get scan counts and sometimes device or location data.

**Limits**

- Many services charge a subscription, and if it lapses the code may stop working or show an advertisement.
- You depend on one company staying in business and keeping its redirect running.
- Every scan passes through a third party, which has privacy implications for your visitors.

## A middle path: a static code for a short link

You can get most of the benefit of a dynamic code with a static one. Make a short link, then create a QR code from the short link. The code is short and simple, and it works as long as the short link does. The difference from a paid dynamic code is that you cannot edit where a short link points. If the page moves, you create a new short link and replace the old code. You can do this on our [home page](/): shorten the link and the QR code appears with it.

## Which should you use?

| Situation | Better choice |
|---|---|
| Permanent page, such as a business website | Static |
| Restaurant menu that rarely moves | Static, or a static code for a short link |
| Printed leaflet that must last for years | Static, with the address kept on file |
| Campaign where you must change the target after printing | Dynamic |
| You need detailed scan statistics | Dynamic |
| Tight budget, no need to edit | Static |

## Questions to ask before buying a dynamic code

1. What happens to my codes if I stop paying?
2. Can I export my destinations and move to another service?
3. Is the redirect on a domain I control, or does it belong to the provider?
4. What data does the service collect about people who scan?
5. How long has the company been operating?

If the answers are vague, a static code is the safer choice for printed material that will stay in the world for years.
