Générateur de QR code

Saisissez une adresse web ou un texte et le code apparaît aussitôt. Téléchargez-le en PNG pour les documents et les écrans, ou en SVG pour l'impression. Rien de ce que vous saisissez ne quitte votre appareil.

Votre QR code apparaîtra ici.

Quel fichier télécharger ?

PNG
Une image faite de pixels. Utilisez-la dans des documents, des diapositives, des sites web et des messages. Choisissez la grande taille pour l'impression.
SVG
Un fichier vectoriel qui reste net à toutes les tailles. Envoyez-le à l'imprimeur, ou utilisez-le pour des panneaux et des emballages.

Conseils pour un code qui se scanne

  • Un code foncé sur fond clair se scanne le mieux. Gardez un contraste élevé.
  • Laissez la marge blanche. Les lecteurs en ont besoin pour repérer les bords.
  • Un texte plus court donne un code plus simple. Pour une longue adresse, raccourcissez d'abord le lien.
  • Une correction d'erreurs plus élevée aide le code à résister à l'usure, mais rend les carrés plus petits.
  • Testez avec un téléphone avant d'imprimer. Notre guide taille et contraste donne les détails.

Questions fréquentes

Ce générateur de QR code est-il gratuit ?

Oui. Sans inscription, sans filigrane et sans limite de téléchargements.

Le QR code expire-t-il ?

Non. Le code est le texte lui-même dessiné en carrés : il fonctionne tant que la page ou le texte qu'il contient existe. C'est un code statique, non suivi.

Mon texte est-il envoyé à un serveur ?

Non. Le code est dessiné dans votre navigateur. Si vous voulez aussi un lien court, utilisez le raccourcisseur d'URL, qui envoie l'adresse à notre service de liens.

Que puis-je mettre dans un QR code ?

Une adresse web est le choix le plus courant, mais tout texte convient, jusqu'à environ 2 900 caractères avec la correction d'erreurs la plus faible. Si un message indique que le texte est trop long, raccourcissez-le.

Puis-je imprimer le code sur un produit ou une affiche ?

Oui. Téléchargez le SVG, gardez la marge et vérifiez le scan sur une épreuve imprimée d'abord.
