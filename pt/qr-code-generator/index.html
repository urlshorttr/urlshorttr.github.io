Gerador de QR Code

Digite um endereço ou qualquer texto e o código aparece na hora. Baixe em PNG para documentos e telas, ou em SVG para impressão. Nada do que você digita sai do seu dispositivo.

Seu QR Code aparecerá aqui.

Qual arquivo devo baixar?

PNG
Uma imagem feita de pixels. Use em documentos, slides, sites e mensagens. Escolha o tamanho grande se for imprimir.
SVG
Um arquivo vetorial que fica nítido em qualquer tamanho. Envie à gráfica ou use em placas e embalagens.

Dicas para um código que escaneia

  • Código escuro sobre fundo claro é o que melhor escaneia. Mantenha o contraste alto.
  • Deixe a borda branca. Os leitores precisam dela para achar as bordas.
  • Texto mais curto gera um código mais simples. Para um endereço longo, encurte o link primeiro.
  • Mais correção de erros ajuda o código a resistir ao desgaste, mas deixa os quadrados menores.
  • Teste com um celular antes de imprimir. Nosso guia de tamanho e contraste tem os detalhes.

Perguntas frequentes

Este gerador de QR Code é grátis?

Sim. Sem cadastro, sem marca d'água e sem limite de downloads.

O QR Code expira?

Não. O código é o próprio texto desenhado em quadrados, então funciona enquanto existir a página ou o texto que ele guarda. É um código estático, sem rastreamento.

Meu texto é enviado a um servidor?

Não. O código é desenhado no seu navegador. Se quiser também um link curto, use o encurtador de URL, que envia o endereço ao nosso serviço de links.

O que posso colocar em um QR Code?

Um endereço da web é o mais comum, mas qualquer texto serve, até cerca de 2.900 caracteres na correção de erros mais baixa. Se aparecer um aviso de texto longo demais, encurte-o.

Posso imprimir o código em um produto ou cartaz?

Sim. Baixe o SVG, mantenha a borda e confira a leitura em uma prova impressa.
