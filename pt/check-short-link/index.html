Veja para onde vai um link curto

Cole um link curto deste site. Você verá primeiro o endereço completo e poderá decidir se continua.

Outras formas de verificar

  • Adicione um sinal de mais (+) ao final de qualquer link curto deste site e abra. Você vê a mesma página de prévia.
  • Esta ferramenta serve apenas para links criados neste site. Para outros serviços, procure a opção de prévia deles.
  • Leia nosso guia sobre como saber se um link curto é seguro.
  • Encontrou um link nocivo? Denuncie.
